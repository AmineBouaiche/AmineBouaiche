### Dorm Management System

Backend-first accommodation management platform built to handle room inventory, student bookings, administration, and operational analytics.

* REST API built with **FastAPI** and **PostgreSQL**
* JWT authentication with student and administrator role-based access control
* Transaction-safe booking logic protecting against conflicting reservations
* Database migrations with **Alembic**
* Administrative occupancy and revenue analytics
* Audit logging and security controls
* Dockerized development and deployment
* CI pipeline with **GitHub Actions**
* **115 automated tests** covering API, authentication, booking, and administrative workflows

**Stack:** Python · FastAPI · PostgreSQL · SQLAlchemy · Alembic · Docker · Pytest
